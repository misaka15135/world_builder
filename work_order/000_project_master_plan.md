# 000 项目总规划

- 状态：in_progress
- 执行者：协调者
- 依赖：无

## 产品目标与现状

面向自建游戏地图的玩家与创作者，用户接入受支持的外部 LLM 后，由系统提供专业角色、知识与工具，完成描述、构建、预览、反馈、保存修订与多目标导出。自然、建筑和混合场景均属范围；玩法、自动投稿和工程认证不属当前范围。

当前已实现固定 A—F JSON 规划、校验、WIR/worldpkg、静态 GLB/schematic 和只读应用；新工具循环、知识检索、自然资产和持续修改尚未实现。历史程序/样件证据不作为新能力验收。

## 已确认决策

- D01：按单栋工具闭环 → 小场景 → 局部修改分阶段交付。
- D02：首批同时支持原生工具调用与行动 JSON，共用运行时、工具权限、预算和候选接受规则，分别完成真实模型验收。
- 模型提交候选，本地程序控制接受、事务和导出；WIR 是源数据，目标文件是派生物。
