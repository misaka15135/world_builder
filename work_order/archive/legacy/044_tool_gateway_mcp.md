## 工作项

- [ ] 注册工具版本、输入输出、坐标/单位、读写范围、能力、目标限制、超时和幂等性；复用 029 契约。
- [ ] 内置函数与 MCP 工具统一映射，发现不等于授权；参数、作用域、资源预算在执行前校验。
- [ ] 构建只返回隔离候选或产物引用；通过 032 提交，工具不能绕过锁、基础修订与硬约束。
- [ ] 保存调用 ID、请求摘要、回执与工具版本；验证超时后状态未知、取消迟到结果、重启恢复和幂等重试。
- [ ] 完成一个可复建的本地只读 MCP 服务发现/调用/断连案例，固定服务、协议与依赖版本；远程服务凭据单独配置。
- [ ] 交付受控工具核心子项供 030 使用；MCP 真实连接结果与模拟测试分开留证。

## 验收标准

- 未知工具、坏参数、越权范围、重复写入和超预算请求均有可定位诊断；失败不改变世界头。
- 内置工具和 MCP 工具输出经过同一版本/范围检查；断连不伪造成功，离线回放不联网。
- 至少一个真实本地 MCP 服务经应用客户端调用成功并记录请求/结果；这不证明外部编辑器副作用或场景质量。
