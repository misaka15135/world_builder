## 验收标准

- 原生工具调用与行动 JSON 两条路径分别通过完整请求—工具结果—修正—最终候选转换测试；拒绝/截断不冒充完成。
- 两种协议使用相同工具 Schema、权限、预算与候选验收；覆盖非法 JSON/动作、未知工具、错误调用关联、重复调用 ID 和截断，失败不得静默切换协议。
- 离线协议测试不算真实服务证据；实际接入和使用成本在 024 按协议分别记录，两条路径均有真实模型工具闭环证据后才能完成首批交付。
