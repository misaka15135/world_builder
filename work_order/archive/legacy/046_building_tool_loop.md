## 工作项

- [ ] 冻结一个受控场地的单栋建筑案例，声明原语、尺寸、楼层、入口、空间与目标精度；固定输入不计为完整自然语言场景。
- [ ] 提供明确参数驱动的构建、检查与预览工具，至少覆盖外壳/开口、楼板、楼梯和通路；无隐式旧模板回退。
- [ ] E 选择工具并依据真实空间诊断修改参数；构建失败不自动减少需求、扩场地或修改硬规则。
- [ ] 候选装配后供 F 查看结构报告和预览，模型支持图像时记录实际视觉审查；不支持时标记未验。
- [ ] 经本地最终检查与 032 事务提交，保存产物、工具/配方版本及失败过程；支持重开与无网络回放。
- [ ] 向 024 提供真实模型批次入口，向 033 提供已接受的可局部修改建筑；D01 已确认本单栋闭环为首个交付，D02 要求首批两种协议分别通过。

## 验收标准

- 受控测试覆盖成功、净空/入口失败、工具错误、预算耗尽和取消；仅模拟结果不证明模型能力。
- 原生工具调用与行动 JSON 两条路径分别由真实模型调用工具、根据失败结果改变参数并产生有效候选，证据由 024 关联，不以手工响应冒充。
- 生成文件、源端几何、视觉质量、目标加载/通行分开验收；工具闭环成功不代表完整城邦或任意建筑。
