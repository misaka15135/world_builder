## 工作项

- [ ] 区分版本化 Skill、参考知识、资产元数据和权威世界查询；固定首批建筑/资产资料来源和适用条件。
- [ ] 实现无需额外云账号的标签/关键词/元数据检索；向量实现按后续实测扩展，不要求先部署向量数据库。
- [ ] 按任务装载相关依赖、对象、邻域与 Skill；大产物使用引用和按需查询，设上下文大小上限。
- [ ] 记录返回片段、来源、资料版本和实际读依赖；缺失、过期、矛盾或未知来源有明确诊断。
- [ ] 将检索结果作为参考数据，不能覆盖任务约束；知识更新使实际使用该知识的任务按政策失效。
- [ ] 冻结检索查询/期望资料集，记录相关性、来源覆盖和上下文大小；经 044 暴露只读检索工具。

## 验收标准

- 旅店/楼梯/目标材料等查询返回可追溯相关资料；零结果与过期信息不伪造引用。
- 世界位置/锁查询使用指定修订，不能用知识索引内容替代。
- 同一任务可查其 Skill、检索片段和世界输入；改变资料不会静默复用已失效缓存。
