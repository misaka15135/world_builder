## 工作项

- [ ] **契约与能力**：定义需求、任务图、行动、工具描述/结果、候选、产物引用、状态与错误；原生工具调用和行动 JSON 映射到同一契约，显式区分旧 json_contract。
- [ ] **范围与版本**：固定单位/坐标、原语/精度、输入输出版本、作用域、预算及终止语义；未知能力、依赖环、漏必需项、假跳过和坏引用明确失败；森林零建筑/零道路合法。
- [ ] **世界与事务**：复用 Repository，实现 world/revision/operation/task/candidate/artifact/tool-call 生命周期、隔离候选、读写依赖、调用回执和原子接受；基础修订、用户锁及跨对象空间冲突均受检查。
- [ ] **目标与迁移**：建立 Unity/Minecraft 精确版本、坐标/量化、材质、几何、资源、必要组件和损失规则；保留 0.1.0 读取/回放，升级副本不改原件；世界包包含所需资产和修订。

## 验收门槛

- 建筑街景、无建筑森林、森林营地三类契约样例及负例通过；此处样例只证明协议，不证明构建实现。
- 失败/取消/并发旧版本不推进世界头；无关对象身份稳定，世界包往返与旧包读取留证。
- 交付可供 049 使用的明确接口与测试；不把目标 profile 声明当作目标加载通过。
