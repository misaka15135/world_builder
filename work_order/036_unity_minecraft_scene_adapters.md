# 036 Unity 与 Minecraft 通用场景适配

- 状态：planned
- 创建日期：2026-10-10
- 执行者：待认领
- 依赖：031、035
- 复用基础：008/009 已有目标环境与基础序列化器，不要求它们的完整编辑联调已完成
- 修改范围：`src/world_builder/adapters/unity/`、`adapters/minecraft/`、Agent compiler 的导出接线、目标导入器/验证夹具、版本化样例和损失报告。资产/源表示通过 031 协议交接，真实模型批次归 024。

## 目标与范围

将同一新主线 WIR 修订中的自然、建筑和混合场景导出为 Unity 与 Minecraft 可加载的产物。沿用既有编码与坐标验证基础，补齐新场景对象、资产实例和必要目标组件，不要求先完成完整手工编辑器。

## 工作项

- [ ] 核对 008/009 与 Agent compiler 的实际复用范围，冻结新版目标输出格式、精确版本和重建说明，保留旧样例及证据。
- [ ] Unity 恢复场景层次、资产实例、源 ID、材料和适用碰撞；水体与实体分开处理，导航仅在 profile 或用户要求时提供。
- [ ] Minecraft 按 profile 转换地形、植被、布景及建筑，记录网格量化、材料/方块状态、坐标、分块、放置原点和必要净空损失。
- [ ] 为自然、建筑和混合样例生成逐对象映射与损失报告；必要对象不能因资产不支持而静默消失。
- [ ] 用人工/离线源样例验证两端实际导入、保存重开及适用的碰撞/行走；仅包含建筑、桥或室内时才验证相应路线。
- [ ] 对不支持的源能力、缺资产、坏坐标、目标版本错误及关键损失明确拒绝，并可定位源对象。
- [ ] 为同一世界的新修订另建派生产物，按声明条件保持无关对象映射；目标侧手工修改不自动回写 WIR。
- [ ] 将实现与固定样件证据回填 008/009 的对应子项，交接 024 的真实模型场景验证。

## 验收标准

- 三类固定源样例均在两个目标加载并重开；源修订、资产摘要、实体数量与映射、朝向和材料有可核对证据。
- 无道路森林不被强制补路；森林营地的木屋及自然对象均在目标可见，实例没有因新类型而遗漏。
- 按 profile 验证地面支撑、碰撞和必要行走净空；导出文件存在不能代替加载，静态路径不能代替实走。
- 对同一修订分别交付目标配置与逐对象损失报告；WIR 哈希不因导出变化，关键需求损失不能写成成功。
- 本工单不交付独立 Minecraft 存档（010）、新游戏 SDK（037）、玩法逻辑或线上投稿。
