## 目标与范围

按用户“继续做完一个大地图”的要求，将同一魔法场景扩展到 512×512m：48 栋住宅/商铺、4 个广场、一座有门楼/塔楼/可进入主楼的城堡，河道、4 座可通行桥梁、贯通道路、外围城墙和受限绿化。首先交付一张可在 Unity 打开的整图，不同时承诺其他三类场景、照片级材质、游戏玩法、所有塔楼内部或通用资产库。

独立固定简报。真实 B 决定受限河道/道路参数，C 提交八种本次建筑配方与绿化密度，D 为 48 个可建地块指定建筑配方、尺寸和偏移，E 设计八种配方及城堡参数，F 审查实际本地报告。模型不生成任意代码；本地显式投影地块、执行构件和路网/桥梁/城墙规则，不暗中调用旧整城规划器。配方的本次实例复用不宣称 043 通用库完成。
