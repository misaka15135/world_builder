## 目标与范围

保留用户提出的长期方向：预存标准建筑和自然资产，生成时优先选取适合的本地资源；本地缺少合适对象或构建能力时，检索外部资产、参数化生成器或 skill，适配并验证后逐渐积累到本地库。该能力放在 042 的四旧场景真实 API 观感迁移之后。042 直接复用现有生成函数，不要求先实现本工单的完整库与联网发现。

## 工作项

- [ ] 分别建立成品资产、参数化生成器、skill 的目录与契约：成品供实例化，生成器提供受限参数到几何的执行，skill 说明挑选、调用和检查流程；不把只含说明的 skill 当作已经有可运行生成器。
- [ ] 首批标准建筑优先从既有已验证样件提取，记录用途/风格、尺寸/原点、入口连接点、楼层与内部可用性、可调整参数、碰撞、材料、来源/许可、版本/哈希和各目标验证状态。
- [ ] 定义本地匹配与明确缺口：满足硬需求时复用；尺寸等可调时使用已注册生成器；缺能力时给出缺口并触发受控外部检索，不用不适配的标准屋替代必需对象。

- [ ] 与 031 的树石灌木与分布配方共用注册接口，避免分建互不兼容的建筑库与自然资产库。

## 验收标准

一个场景可混用多个已验证资产/生成器并正确归档；重复生成无需再次获取相同版本。提供本地命中、参数调整、外部候选成功注册、无适合能力、室内不匹配和目标不支持案例。需区分“找到资料”“注册可执行能力”“源几何通过”和“目标加载/观感通过”。检索及资产复用不得抹去必需需求。
