## 目标与范围

为当前 API 多智能体分支提供可直接启动的本地网页应用：输入需求、独立 API 设置、离线样例/API/回放、阶段进度、运行历史、取消、JSON 诊断、源几何预览和产物下载。前端仅依赖版本化 HTTP 接口；任务服务通过适配层调用现有监督器。输入、配置、任务、预览和资源面板分离，便于逐模块替换。

首版部署为本机 Python 服务加浏览器页面，提供双击启动脚本；无需额外前端构建工具或 CDN。它是测试台与只读预览，不将 007 的完整世界编辑、撤销/重做和增量生成记作完成。

## 验收标准

浏览器可运行样例、查看真实阶段记录和源几何、下载产物、回放并查看相同修订；刷新/重启保留历史。非法参数、越界文件、跨来源写请求与无配置 API 有明确错误。密钥不写配置、日志或浏览器存储。前端无生成逻辑，各功能由模块和 HTTP 契约隔离。真实付费调用仍由 024 单独验收。
