# 034 场景反馈与修订工作台

- 状态：planned

- 执行者：待认领
- 依赖：025、033
- 修改范围：`src/world_builder/workbench/` 的修改/修订 API、`web/features/` 的反馈与历史界面、选中对象映射和浏览器验收。复用 025 预览与 026 宿主；完整拖拽/属性编辑仍属 007。

## 目标与范围

让用户在已有场景中选择对象或区域、提出修改、看到影响与进度，再查看新修订、撤销或导出。界面呈现 033 的命令与结果，不在前端另建规划器或权威源数据。

## 工作项

- [ ] 将拾取结果绑定稳定对象 ID、当前 world_id 和 revision_id；提供区域或对象组选择，避免依赖仅渲染节点身份。
- [ ] 提供修改描述、保护对象和导出目标输入，将选择上下文发送至领域命令服务。
- [ ] 显示预计影响、实际重做对象、复用任务、预算与失败原因；正常指令不设置重复确认步骤。
- [ ] 支持取消、修订历史、锁定/解锁及撤销/重做，刷新或重开恢复同一世界上下文。
- [ ] 新修订成功后更新预览与下载身份；失败保留旧场景，并可定位冲突对象。
- [ ] 对齐动态任务图的进度，显示不适用与复用原因；界面不将文件导出成功显示成目标游戏已加载。
- [ ] 完成浏览器端自然场景、混合场景和四类修改关键流程验收，复核桌面宿主兼容。

## 验收标准

- 从已有场景选择木屋改材质、移动对象、调整河道、重新导出四条流程均可完成，显示的修订与后端产物一致。
- 未修改对象仍可选中且身份不变；旧基础修订、锁冲突和目标歧义有可理解反馈。
- 取消或失败不替换旧预览；撤销/重做不额外调用模型，重启后可恢复历史和锁。
- 界面实际操作与截图/日志可关联同一修订；真实模型与目标加载证据归 024，不用人工样例替代。
- 007 的手工拖拽、属性编辑和完整三维编辑性能仍保持待验，不能因反馈入口完成而勾选整个 007。
