## 执行约定

- 一张主工单负责一个明确交付，内部工作项分解实现；不按每个模块再建一套重复工单。
- 状态仅用 planned、in_progress、blocked、done、cancelled；开始时填写负责人和具体修改范围，相关文件串行交接。
- 每次有结果的动作更新当前工单的证据和下一步；完成项用 `- [x] ~~描述~~`，没有验收不得标 done。
- 真实模型评估随 050/051/052 交付，不另维护永久不收口的总验收工单；人工响应、真实调用、文件、目标加载与实际通行分别留证。
- 新的独立需求才建递增工单，旧编号不重用；登记到 registry.json 并在本页提供入口。下一可用编号：055。
- 架构解释见 [08](../docs/08_agent_target_architecture.md)，已确认 D01/D02 见 [09](../docs/09_agent_migration_plan.md)。重大新选择保留选项/影响和推荐，等待答复时继续独立工作。
