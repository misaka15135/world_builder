## 目标与范围

执行经过验证的任务图，根据对象需求、已实现能力与目标 profile 调度任务；支持任务不适用、结果复用、按类型分派和限定范围返工。保持原有预算、审计、取消及明确失败机制。

## 工作项

- [ ] 建立任务能力注册表，绑定输入输出版本、构建处理器和本地校验器；规划前向 A 提供真实可用能力。
- [ ] 验证依赖、产物引用和必需能力；仅在依赖已接受后启动任务，缺少必需处理器在调用前报告。
- [ ] 按需启动建筑 E 和景观/实例组 E；零建筑不发建筑请求，零道路不触发建筑接路规则。
- [ ] 区分不适用与结果复用，记录理由、产物身份和依赖摘要；预算统计只记录实际调用，失败与取消仍保留记录。
- [ ] 按任务与对象依赖传播失效；同一批任务返回顺序不影响装配，更新一个对象不默认重做所有对象。
- [ ] 将 F 的返工范围映射为合法任务 scope；保留整体验证，不允许 F 偷改用户需求或预算。
- [ ] 保留 0.1.0 固定 A—F 的回放入口；新版图不能套用旧记录，恢复和回放不能隐式联网。
- [ ] 给工作台输出实际任务进度、不执行原因及失败位置，适配动态数量而非写死建筑数。

## 验收标准

- 三类 029 样例均可执行人工响应闭环：森林没有建筑调用，营地只调用所需建筑，必要审查均执行。
- 单个构建任务失败或返工的实际重执行集合与依赖图一致；无关已接受结果保持相同身份与哈希。
- 未注册任务、坏依赖和假跳过被拒绝；超时、取消、并发和重试受总预算约束，无规则规划隐藏回退。
- 事件能区分失败、不适用与复用；新旧离线记录均按各自版本回放。
- 本工单可使用受控测试处理器验证调度，不将其计为 031 自然资产能力或 024 真实模型质量。
