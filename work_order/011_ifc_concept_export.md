- 样例含场地、建筑、楼层、空间及受支持的墙/板/门/楼梯等实体，不以全体 proxy 冒充构件语义。
- 通过选定验证工具并在目标 BIM 工具显示，实体 ID 可追溯。
- 验证报告明确模型用途和信息完整度；不把 IFC 可打开解释为可施工。
- 施工图、结构计算、机电和规范符合性保持未完成，直到专门任务验收。
