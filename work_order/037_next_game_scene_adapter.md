- 执行者：待认领
- 依赖：035、036、024；开工条件为选中平台、输出形态和可用目标环境已明确
- 修改范围：所选游戏的独立 adapter、版本化 profile、目标 SDK/编辑器导入示例、验证记录及必要映射测试。具体目录与组件在开工前登记，不预设统一适配所有游戏。

## 目标与范围

在核心场景闭环完成后，为 035 选中的一个游戏交付可本地加载的场景适配原型。复用源表示与既有引擎输出，同时补齐该游戏实际需要的场景组件。普通 Unity GLB 导出不等于任何基于 Unity 的游戏已适配。

## 工作项

- [ ] 根据 035 记录选中平台、真实使用需求、SDK/编辑器版本、交付形态和必须支持的对象类型。
- [ ] 建立游戏专用 profile，区分几何、资源、碰撞、必要场景描述/出生位置等组件与玩法脚本。
- [ ] 从已归档的自然或混合场景修订输出目标工程/导入包及逐对象映射，不新增另一套权威世界数据。
- [ ] 在实际目标工具/客户端本地构建或加载，验证比例、材质、对象、支撑和要求的场景漫游，保存版本与日志/截图。
- [ ] 覆盖缺组件、资产限制、目标版本错误和关键对象不支持，提供清楚诊断。
- [ ] 记录从导出到本地使用仍需要的人工步骤、限制及后续工作，避免将文件输出记作可投稿完成。

## 验收标准

- 至少一个新平台场景能由指定源修订重建并在实际目标环境本地使用，目标组件和源对象可追溯。
- 失败样例可定位原因，必要组件缺失不会写成成功；现有 Unity/Minecraft 输出无相关回归。
- 交付精确版本、重建说明、目标 profile 和对象损失报告，明确未支持功能与人工操作。
- 不包含谜题、任务、通关逻辑、自动账号操作或线上投稿；新的此类需求单独规划。
