## 工作项

- [ ] **建筑与工具**：冻结受控场地单栋案例，提供墙/开口、楼板、楼梯、屋顶、空间与通路的明确参数工具；声明原语、精度与限制，不隐式回退旧模板或减少需求。
- [ ] **候选与审查**：E 选择工具，依据实际净空/入口/路径诊断修改参数；局部检查、装配预览、F 审查、本地最终校验、事务提交形成闭环；图像不支持时视觉检查保持未验。
- [ ] **真实双协议批次**：调用前冻结场景、样本量、预算和成功标准；两种协议分别记录实际调用、工具回执、修正前后、失败、耗时、usage/估算来源和人工干预；失败不得移出分母。
- [ ] **交付与复现**：保存、重开、世界包往返和无网络回放通过；通过 CLI 与现有预览可复建同一单栋；生成 GLB/schematic 文件及映射/损失，目标加载/连续通行进入 051 独立验收。

## 验收门槛

- 原生工具调用与行动 JSON 均有真实模型根据实际工具失败结果修正并提交有效候选的证据，一种通过不能替代另一种。
