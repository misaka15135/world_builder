## 工作项

- [ ] **双协议适配**：同时实现原生工具调用和行动 JSON；连接显式选择协议，统一动作和观察回传，不静默降级。检测上下文/结构化输出/图像/usage 能力，密钥不进入日志或产物。
- [ ] **运行循环**：实现行动→工具→观察→修正→提交；支持 A 提议图、依赖调度、并发 E、受限返工与失效、结果复用、等待用户和有限终止；角色可共用同一模型连接。
- [ ] **工具与 MCP**：内置与 MCP 工具使用统一注册/参数/作用域/权限校验；记录版本、幂等键、回执、超时与断连；完成一个真实本地只读 MCP 服务发现/调用/恢复案例。
- [ ] **预算与恢复**：全局/任务预算覆盖模型、工具、返工、时间和资源；拒绝、截断、非法 JSON/动作、未知工具、错误/重复调用 ID 有明确处理；状态未知先查回执，取消迟到结果不能提交。
- [ ] **兼容与诊断**：保留旧版固定流程与精确离线回放，恢复不隐式联网；输出动态任务和工具事件供工作台消费；模拟工具仅作为机制测试。

## 验收门槛

- 两种协议分别通过完整工具循环、失败后修正、终止和负例测试，共用同一权限/预算/候选验收。
- 有实际 MCP 服务调用证据，断连、超时、重启和重复副作用负例通过。
- 任务调度受控场景覆盖建筑/自然/混合分派；领域能力和真实模型设计质量由 050/051 验收。
