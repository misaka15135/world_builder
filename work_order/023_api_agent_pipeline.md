## 验收标准

所有 A—F 计划由 provider 提交并经本地严格校验；非法响应有作用域、有限重试和失败结果；模型不能跳过硬规则、删除必需建筑或改预算；无密钥的示例可离线回放并导出 WIR/世界包/目标文件。配置占位符不能意外发送网络请求。真实服务质量与游戏内通行需后续独立验收。
