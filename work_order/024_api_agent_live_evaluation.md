## 目标与范围

对 023 的真实 API 调用完成率、返工率、成本、设计质量和目标可用性进行可核对的验收。接入用户实际选择的服务；比较供应商时保持用户需求、契约、预算和 skill 版本一致，不承诺更换模型后结果相同。

## 验收标准

真实服务结果必须能关联到请求、响应、skill/契约版本和导出修订；失败不能从分母中删除。目标侧证据需区分文件结构、实际加载、碰撞和连续实走。只有实际执行的检查能标记通过；fixture 与模拟 HTTP 测试不能计为真实模型样本。具体批次标准在首次运行前冻结。
