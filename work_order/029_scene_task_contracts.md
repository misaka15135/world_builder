## 目标与范围

将建筑中心的 A—F 契约推广为场景需求、地形或底图、对象清单、空间布局、按类型构建与整体审查。支持自然、建筑和混合场景，分类只描述需求，不直接关闭整个阶段。保持 Agent 决定场景设计、本地执行硬规则的边界。

## 工作项

- [ ] 定义需求 ID、对象类别、数量或区域密度、空间关系、风格、必要性、目标能力要求和对应验收条件。
- [ ] 定义任务建议与总控接受的任务图：任务类型、scope、依赖、输入输出契约版本、必需能力、适用校验器、预算与终止状态。
- [ ] 明确 A 提交任务建议、总控验证任务图；模型不能关闭必要审查、编译校验或目标导出检查。
- [ ] 将 C 从建筑目录推广为对象及资产清单；D 支持地形分区、分布区和对象位置；E 区分建筑、景观对象、资产实例组等构建任务。
- [ ] 定义不适用任务、已有产物复用、有效空集合、失败和取消的不同结果；可选任务不执行须有理由，必需能力缺失不得静默删除需求。
- [ ] 按任务类型启用道路、入口、楼层通路等规则；保留边界、资源身份和适用支撑检查，不再强制自然景观存在道路或建筑。
- [ ] 冻结新契约版本及兼容策略；保留 0.1.0 样例、已录制响应和旧世界包，新版不兼容时明确拒绝混用。
- [ ] 提供建筑街景、无建筑森林溪流、森林营地三个正例，以及漏需求、缺依赖、循环图、假跳过、未知构建能力等负例。

## 验收标准

- 无建筑森林可合法表达零建筑、零道路，仍具备对象清单、布局与审查要求；混合场景仅为确有建筑需求的对象生成建筑任务。
- 必需任务不能以“不适用”绕过；未知任务类型、错误输出引用和依赖环明确失败。
- 参数、坐标、几何原语和预算有显式版本与单位；声明的类型没有实现时返回能力缺口，不生成通用盒子冒充完成。
- 新 Schema 与运行时契约定义一致；旧版本仍可通过既有离线回放路径，不能覆盖历史产物。
- 本工单完成只证明契约及样例，不证明运行调度、自然场景生成或真实模型质量已完成。
