# 032 稳定世界身份与任务依赖存储

- 状态：planned
- 创建日期：2026-10-10
- 执行者：待认领
- 依赖：005、023、029
- 修改范围：`src/world_builder/agents/compiler.py`、存储/revision 接口、新版任务记录与依赖快照、worldpkg 元数据及迁移测试。复用既有 Repository，不另建权威数据库；运行时集成与 030 协调。

## 目标与范围

将同一个世界的长期身份与生成运行、内容修订分开，支持用户持续修改。当前 compiler 以完整 accepted 计划摘要同时生成 world_id 和 revision_id，任务摘要又包含全局提示词；本工单建立可供局部修改使用的身份与依赖基础。

## 工作项

- [ ] 定义 world_id、revision_id、operation_id、task_id、对象/实例 ID 的生命周期及父修订关系；修改现有世界不生成另一个世界身份。
- [ ] 保留已有 0.1.0 世界和响应的身份，设计读取与升级方式；不重写历史记录或伪造旧任务依赖。
- [ ] 定义任务实际读取的需求、对象、边界、约束、目标要求、skill/契约版本及资源摘要。
- [ ] 将任务相关的输入摘要与整段原始提示词的审计记录分开；局部修改不能仅因全局文本变化使所有任务失效。
- [ ] 保存不可变候选和依赖快照，复用已有基础修订检查、资源发布和事务提交；失败、取消和并发冲突不得推进世界头。
- [ ] 定义资产实例及分布区稳定 ID 与旧新对象匹配规则，明确删除、新增和重建的身份边界。
- [ ] 支持世界包带修订、依赖及资产往返，源端与目标产物使用同一可追溯修订。

## 验收标准

- 同一世界连续三次局部修改保持 world_id；每次成功产生独立修订和父关系，原数据可读。
- 无关任务的输入摘要、对象 ID 和数据不变；skill、相关依赖或适用约束变化会使对应任务失效。
- 旧响应和旧世界包的回放身份保持原值；无法升级的记录明确限制，不隐式联网补齐。
- 两个基于同一旧修订的并发写入不会互相覆盖；资源损坏、失败和取消不产生可见半成品修订。
- worldpkg 往返保持身份、锁、版本和资源；本工单不将领域命令或完整编辑器记作已实现。
