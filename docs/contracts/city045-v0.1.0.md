## 模型与本地职责

固定用户简报包含 48 栋普通建筑、4 广场、河道/4 桥、道路、外围城墙和一城堡。没有独立模型 A，也不声称任意拓扑/起伏地形或通用任务图实现。

本地绿化用固定 seed=45，在道路/地块/城堡/水体以外放置模型指定数量；不是第三方资产或一般自然场景系统。八配方由本次 API 设计并实例化，未实现 043 的通用库存、检索或跨运行资产注册。城堡塔为外形与空心墙体，无内部上塔楼梯；主楼为两层带室内的详细建筑。

## 硬门槛

全部 48 地块 ID 恰覆盖一次、八配方全部使用，至少 16 住宅和 16 商铺，商铺必须两层。地块干燥、不互相覆盖，与服务道路匹配；全部配方实际维度通过单栋检查。至少两种屋顶形态、石材/灰泥两种墙材实际落地。

逐构件进行确定性“后绘覆盖”裁切，保留旧细节材料优先级；XY 桶加速不改变裁切真值。所有结果盒在区域内、尺寸正、两两无正体积交叠。河道通过两岸分离的陆地和独立河床表示，不把水面盖在整块实心地面上。

全部普通建筑和主楼每间房使用 .1m 源端支撑/净空图；本版以 .5m 桶做精确候选加速，最终 .3m 半径、1.8m 高、.251m 最大台阶规则不变，测试与 042 原路径逐点对照。道路/跨河全线、纵向大道/城门及城堡门楼通路另按 .25m 支撑/净空采样，不能用连通线条代替实体桥。源检查不等于 Unity 物理通过。

## 预算、录制与产物

运行入口 `tools/run_city_045.py`，独立无密钥配置 `config/agents.deepseek-city045.json`。`--offline` 明确使用人工 fixture，绝不作为 API 失败后备。离线负例通过后 `--register --batch v1` 冻结输入/配置/代码/skills 哈希；每个实际调用保存请求、响应、usage 和失败。至多 28 调用、300000 本地计账 token、单响应 12000、2 次尝试、1800s；失败 usage 缺失仍沿用保守预留，不等同供应商账单。

所有输出必须是新目录，不覆盖原始批次。回放要求原登记完全相同，ReplayProvider 不联网，检查 worldpkg/GLB/源细几何字节一致。WIR 保留完整构件实体及自包含的接受参数/实际几何资源；GLB 只是派生文件。

Unity 另行核对所有 mesh/bounds/碰撞、保存并独立进程重开；按 64m 空间桶/材料合并渲染网格，同时保留原构件身份和碰撞体，逐批保存来源成员并检查覆盖一次。代表实走为八配方各一实例的全部房间、主楼、四桥、两大道/城门及城堡入口，不将代表路线外推为所有房间目标实走。截图与用户观感另记。Minecraft 本子阶段未导出或实贴。
