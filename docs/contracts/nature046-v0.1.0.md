## 构建政策

坐标RH X东Y北Z上、米；只有本契约的yaw参数用度，WIR声明的通用角度单位仍为rad，
本契约的姿态元数据为生成配方，不代替WIR变换。地形是2m采样真实三角网，
385×385个高程样点，按64m区块与材质拆分，统一采样网格防止地形接缝。
河道中心是双频正弦曲线，河床实际下切、静态水面z=4.8。山丘是受模型高度控制的
连续函数；地基/中心广场/桥头局部整平，整平影响使用连续权重混合而非最近邻突变。

每个聚落16栋，共64栋；确定性拒绝采样保证干燥、中心广场保留、建筑外接圆分离，
不是固定行列、环形槽位或仅小幅抖动。朝向大致面对广场并加入受限偏转；尺度和配方
由冻结种子及模型住宅比例共同控制。房屋局部详细盒体先裁分，再绕自身中心旋转为
真实源三角网；不把旋转后的AABB冒充实际建筑几何。

道路用地形A*避开房屋/喷泉，八方向搜索不切建筑拐角，坡度成本参与选路；046.2同时拒绝
完整地形三角面梯度大于1.05的邻格（约46.4°，低于目标50°），防止等高线横坡滑移。路面是
地形三角形材质分区，避免重叠平面闪烁。河流只有两处真实桥面允许穿越；桥顶与引道
同高。庭院与地形重叠的内部区域不重复输出地形。树木为低多边形锥冠/树干且避开道路、
河水、建筑、城堡和广场。没有物理流水、植被动画、照片材质或游戏任务系统。

## WIR、GLB与验证边界

世界包内含接受模型参数与完整源顶点/法线/索引资产；每个WIR构件以资产ID与mesh_index
指向真实几何，顶点空间明确 `world_RH_Z_up`。构件bounds是源顶点AABB而非构件实体占据。
GLB直接由同一源网格导出，WIR→glTF `(-x,z,y)`，经glTFast→Unity `(x,z,y)`；使用UInt32索引。
源地形采样严格使用导出三角形相同的对角线插值。

源验证包括参数、数量/间隔/干燥、入口整平、室内局部胶囊图、yaw后的世界路线、
室外路线支撑/坡度/建筑与喷泉脚印避让、显式桥面和区域边界。它不是任意网格全表面
相交检测。局部室内图只覆盖录制房屋设计，城堡墙顶/塔顶没有承诺可登。

Unity加载/保存重开逐件核对bounds与碰撞体、渲染批次覆盖；选每种配方一个实例的全部
房间、城堡主楼、两条完整坡路、两次完整跨河、城堡引道与代表入口路进行连续物理实走。
代表通过不能写成64栋逐间目标实走。F文本审查不是目标证据；观感必须实际截图及用户复核。
