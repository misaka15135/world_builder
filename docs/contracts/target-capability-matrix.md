# WIR 0.1 目标能力矩阵

状态含义：`保留` 表示目标中有受验收的直接表示；`近似` 表示经量化或替代；`源端` 表示仅在 WIR 保留；`拒绝` 表示缺失必要信息时导出失败。所有条目仍需 008、009、011 在实际软件中验证。

| WIR 能力 | Unity 6000.3.24f1 | Minecraft 1.21.11 + WorldEdit 7.3.19 | IFC4 ADD2 TC1 |
|---|---|---|---|
| 稳定实体 ID | 保留到组件/sidecar | 保留到 manifest 映射，方块不原生理解 | 保留到受支持对象 GlobalId 映射 |
| 层级与局部变换 | 保留；坐标反射需修正绕序 | 近似到整数格和放置原点 | 保留到空间/构件放置 |
| 连续地形与河道 | 网格保留，Unity Terrain 不是默认 | 近似为方块和流体状态 | 场地概念几何，水文语义多为源端 |
| 道路与桥梁语义 | 几何保留，语义由组件承担 | 方块几何近似，关系留在 manifest | 桥梁不在首批建筑 profile；缺少映射时源端或拒绝 |
| 建筑、楼层、房间 | 几何与层级保留 | 方块几何近似，房间语义主要源端 | 受支持空间层级保留；缺少构件参数时拒绝语义构件输出 |
| 墙、板、门、楼梯 | 网格/碰撞保留，导航另验 | 目标规则近似并重新验证通行 | 有充分参数时保留为对应构件 |
| 家具资产 | glTF 子集保留 | 替换为方块组合、合并或省略并报告 | 通常源端；选定对象可用代理表达 |
| PBR 与发光 | glTFast/URP 支持子集，复杂 shader 近似 | 方块材质或发光方块近似 | 外观非核心，通常近似或源端 |
| 碰撞与通行 | 由适配器构造并实测 | 由方块形状重新计算 | 不适用游戏通行；不得宣称工程疏散合规 |
| 生成配方、锁和历史 | 源端；可附摘要 | 源端；可附 manifest | 源端；有限属性不承担执行语义 |
| 幻想例外 | Unity 专用组件/特效或报告 | 替代、近似或拒绝 | 若破坏工程语义则拒绝对应构件声明 |
| 外部修改回写 | 0.1 不支持 | 0.1 不支持 | 0.1 不支持通用往返 |

每次导出必须产生对象级 `preserved / approximated / omitted / unsupported / failed` 分类、源到目标 ID 映射、坐标矩阵、适配器版本和汇总计数。文件生成、目标读取和功能可用是三个独立验收状态。
