# 单栋建筑设计 0.1

版本：0.1.0。日期：2026-09-26。实现：`src/world_builder/planning/designer.py`、`settings/*/designs.json`、`tools/design_buildings.py`。状态：**离线规则路径已实现并测试；只覆盖有模板的类型，其余如实跳过。**

本文是流水线阶段 E（[017](../../work_order/017_building_designer.md)）的合同。上游是 [districts-v0.1.md](districts-v0.1.md) 的场址包络与 [scene-brief-v0.1.md](scene-brief-v0.1.md) 的目录。

## 1. 它做什么

拿一个场址包络（最大占地、最大高度、层数上限、场址要求）和一个目录条目，产出**这栋楼自己的设计**：逐层轮廓、每层房间与隔墙、楼梯、入口、屋顶、材质、家具。形状词汇刻意保持很小（矩形、逐层退台、平顶/双坡/尖塔），因为这几样是目标适配器已经能导出、规则也已在游戏里验证过的；**随类型变化的是策略**（层数、每层房间、家具、屋顶），策略写在 `settings/<id>/designs.json` 里。

## 2. 模板

```json
"guild_hall": {
  "storeys": [2, 3], "storey_height_m": 3.4, "roof": "gable", "roof_height_m": 2.0,
  "setback_m": 1.0, "stair": "straight", "aspect": 1.3,
  "room_uses": [["task_board", "taproom"], ["dormitory", "store"], ["dormitory", "office"]]
}
```

- `room_uses`：每层的房间用途（每层最多取两个，形成"两间房 + 一道隔墙"的平面）；房间用途必须在本模块的家具表里存在，否则加载即报错。
- `stair: "none"` 表示**单层大空间**（厂房、仓库）：层数被强制为 1，而它的**净高会抬到目录要求的高度**——大跨车间的层高本来就是十几米，不是三米。
- `setback_m`：三层以上时顶层退台（东侧不动，因为那是楼梯井）。

目前每个背景给出 6—10 个模板；目录里仍标 `design_state: planned` 的类型没有模板，设计阶段会**跳过并列出**（`no design template yet for: [...]`），不会退回成通用盒子。

## 3. 生成规则

1. **层数与高度**：从模板层数区间取一个值，再夹进场址包络的层数上限，并**优先对齐目录的高度区间**（`fewest..most`）。
2. **装不下就压层高，而不是砍层数**：目录高度是合同，一栋"被压扁的两层住宅"仍然是住宅；只有连 2.6 m 层高都放不下才减层。
3. **平面**：每层在楼梯井以西切两间房，中间留 1 m 隔墙位（墙不占房间）；房间与楼梯预留必须脱开。
4. **楼梯**：两层以上给直跑楼梯（梯段、平台、井道），单层不给。
5. **入口**：开在朝场址外侧的那一面（由选址阶段给出的临街方向决定），2 m 宽、2.4 m 高。
6. **家具**：按房间用途查表放 1—3 件（壁炉、床、柜台、工作台、书架、长桌、祭坛台、机器、货箱、海关柜台、灯室…），位置按房间实际尺寸收缩。

## 4. 独立校验（`design.*`）

| 规则 | 判据 |
|---|---|
| `envelope` | 占地 ≤ 场址包络、总高 ≤ 包络高度、层数 ≤ 包络层数 |
| `storey_outline` | 每层轮廓在总轮廓内，且最小边长 > 4 m |
| `setback` | 首层保持总轮廓；上层只退不进 |
| `rooms_inside` | 每层恰好两间房，且在楼层轮廓内 |
| `partition` | 两间房之间恰好 1 m 隔墙位 |
| `stair` / `stair_void` | 两层以上必有楼梯，梯段宽度与升高合法；房间让开楼梯预留 |
| `entry` | 入口在合法侧面，尺寸达标 |
| `furniture` | 每件家具都在其房间里 |
| `materials` | 材质来自背景包，且含墙体/楼板/屋顶 |
| `height_in_catalogue` | 总高不超过目录高度上限（+1.5 m 容差） |

**容差说明**：设计坐标按毫米存储，因此包含关系用 2 mm 网格容差判断。这不是宽松：早先版本用 `1e-6` 比较，把"轮廓向下取整、楼层向上取整"造成的 6 µm 差额判成"楼层跑到屋外"。

## 6. 命令行

```powershell
$env:PYTHONPATH = 'src'
python tools/design_buildings.py --prompt "河谷里的魔法城邦，要有城堡和冒险者工会" --seed 4 --show guild_hall
python tools/design_buildings.py --setting harbour --seed 4 --output artifacts/harbour-designs.json
```

输出：某类型的首层平面（可选）、设计总数、按类型统计、层数分布、最高建筑、带楼梯数量、家具件数、**没有模板的类型清单**，以及任何未通过校验的设计。退出码非 0 表示有设计未通过。
