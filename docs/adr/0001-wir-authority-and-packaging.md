# ADR-0001：WIR 权威数据、修订与便携包

- 状态：accepted
- 日期：2026-09-22
- 决策范围：WIR 0.1

## 决策

运行期以 SQLite 中的语义记录、关系、修订和引用为权威数据，以内容哈希命名的不可变资源文件为权威资源。JSON/JSONL 是交换快照，`.worldpkg` 是快照和资源的发布容器，不是第二套可独立编辑的数据库。

每次写入先把资源写到同一文件系统的临时位置，计算 SHA-256，原子发布到 `assets/sha256/<hash>`，再在一个 SQLite 事务中写记录、资源引用、校验摘要和新修订。只有事务提交后的修订可以成为分支头。失败或取消保留原分支头；孤立资源由延迟垃圾回收处理。

便携包在临时目录完整生成，验证清单、引用和哈希后再压缩，并通过同一文件系统的原子替换发布。导入时先解压到隔离目录，拒绝绝对路径、父目录跳转、重复路径和符号链接，验证后创建新导入修订。导入不覆盖现有修订。

## 版本与迁移

`schema_version` 使用语义版本。0.x 阶段仍要求显式迁移：旧快照保持不变，迁移器生成新快照和迁移修订，记录源版本、目标版本和工具版本。读取器遇到未知 `required_capabilities` 必须失败；未知可选扩展保存在 `extensions` 中并原样传递。

恢复流程先执行 SQLite 完整性检查，再确认分支头引用的修订与资源存在。缺失资源、哈希错误或未知必需能力不得自动修复成空对象。缓存不属于权威数据，可删除后重建。

## 原因与影响

SQLite 为单机事务、查询和修订切换提供明确边界；不可变资源避免事务提交后文件内容变化。代价是必须维护导入导出、Schema 迁移和资源回收工具。首版采用单写者队列；多人实时合并和 CRDT 不在本决策范围内。
